# 大模型后训练入门

**训练一个可靠的 AI**

一个善于续写文本的大语言模型，怎样逐步变成能够理解指令、分步推理、查阅资料、使用工具，并在信息不足时承认不确定的助手？

这本书围绕这个问题展开。我们从一个还不太可靠的学习助手出发，逐步理解语言模型的基础、监督微调、强化学习和知识蒸馏，再把推理、检索、工具与评估连接起来，建立对大模型研发的整体认识。

## 这本书讲什么

贯穿全书的是一条训练与改进助手的故事线。

起初，模型连“请回答问题”都不总能做到。我们用示范教它回答，它开始像一个助手，却又在学习新资料后丢掉原有能力。我们让它多试几次，发现有些尝试能得到正确答案，于是尝试筛选、奖励和策略更新。训练分数上涨之后，我们还要追问：它是否真的学会了？为什么验证集没有进步？怎样判断问题来自数据、训练目标，还是评估方式？

沿着这些问题，本书重点讨论三类训练信号：

- **SFT：从示范中学习。** 理解监督目标、数据组织与损失位置，以及续训后行为变化和能力退化的原因。
- **RL：从尝试和反馈中学习。** 从采样与拒绝采样出发，理解 RLHF、PPO、GRPO、DPO，以及奖励、偏好与泛化之间的关系。
- **OPD：在自己的轨迹上向教师学习。** 理解序列蒸馏、分布蒸馏与同策略蒸馏，分清轨迹由谁生成、反馈从哪里来，以及这些选择怎样影响学习。

后训练也与模型基础和应用系统紧密相连。因此，书中还介绍分词器、Transformer、嵌入表示、推理时计算、RAG、工具调用、可解释性和多模态，帮助读者理解不同方法在整个系统中的位置。

## 内容安排

全书共十一章，并附有术语与阅读方法。

1. **定义一个值得训练的助手**：从任务、失败案例和评估出发，明确我们希望模型学会什么。
2. **语言模型与文本预测**：理解 Tokenizer、下一个词元预测、Transformer、预训练与幻觉。
3. **嵌入表示与语义检索**：理解文本如何变成向量，以及语义表示怎样用于检索。
4. **监督微调与续训退化**：学习 SFT 的目标、数据工程与遗忘诊断。
5. **采样、强化学习与偏好优化**：串起 RFT、RLHF、PPO、GRPO、DPO，并讨论训练与泛化问题。
6. **知识蒸馏：从教师示范到同策略学习**：理解不同蒸馏方法，重点讨论 OPD 的信号与适用条件。
7. **推理策略与推理时计算**：介绍思维链、工具调用、KV 缓存与长上下文的资源成本。
8. **检索增强生成（RAG）**：把外部资料接入回答过程，沿证据链定位失败。
9. **可解释性入门**：通过线性探针、激活修补和稀疏自编码器，理解不同证据能够支持怎样的结论。
10. **多模态大模型入门**：认识多模态模型的结构、训练路线，以及图像、视频和语音输入。
11. **现代大模型研究方向简介**：梳理研究与工程问题，帮助读者选择进一步深入的方向。

## 适合谁读

本书面向具备基础编程能力、希望系统了解大模型的读者，尤其适合准备进入后训练方向的学生和工程师。

读者需要知道数组、函数等基本概念。概率、向量、梯度等数学知识会结合具体问题介绍；术语首次出现时给出中文名称、英文全称与常用缩写。各节提供相关论文与补充资料，方便沿感兴趣的问题继续阅读。

## 怎样阅读

第一次阅读，建议按章节顺序，先抓住“为什么遇到这个问题、有什么证据、下一步怎样验证”的主线。第二次再回到公式、算法细节和相关论文，并结合小规模实验检查自己的理解。已有语言模型基础的读者，也可以从第四至六章进入后训练部分，再按需要回看基础章节。

全书可以安排约八到十二周的集中学习，也可以按课程或自学节奏拆分。希望读者最终形成的是面对新问题时的判断力：能识别训练信号与数据分布，能区分训练涨分和实际进步，也能通过对照实验决定下一步该做什么。
