\chapter{监督微调与续训退化}\label{监督微调与续训退化}

\section{监督微调 SFT 用示范塑造助手行为}\label{监督微调 SFT 用示范塑造助手行为}

回到最初的方程题，我们给出一条完整示范：``先把两边除以 3，得到 a＋2＝7；再把两边减去 2，得到 a＝5；代回检验成立。''我们不只希望模型背下来这个答案，而是希望它在新题上也遵循解释、求解、检查的任务结构。

SFT 让模型在指令与对话上下文下，提高示范回答的概率。从目标看，它仍然通常是逐 token 最大似然；从数据看，它把我们关心的助手行为集中呈现给模型。示范可以由人写，也可以来自强模型或数据合成管线。``监督''指存在目标输出，不等于所有文本都必须由人类逐字编写。

我们用掩码（mask）标出哪些位置计算损失。若目标是教助手回答，常见做法是只对助手回复计分，把系统和用户内容作为条件；多轮训练也可以监督多个助手轮次。没有统一规定说所有 SFT 都必须只算最后一轮，关键是实际监督范围是否符合任务。 把位置 t 的监督掩码记为 m 的下标 t，只对参与监督的 token 取平均，SFT 损失写为：
\[L_{SFT} = - \frac{1}{\sum_{t}^{}m_{t}}\sum_{t}^{}m_{t}\log p_{\theta}\left( x_{t} \mid x_{< t} \right)\]

求和号按序列位置相加，分母是有效监督位置数；若分母为 0，应拒绝该样本并检查数据处理，不能继续计算这个平均损失。m 为 1 的位置参与监督，为 0 的位置不参与，因为被 mask 掉的 token 的log p 乘以 0 就直接是 0。

图 \ref{fig:SFT监督位置} 把两个经常混淆的 mask分开。损失掩码决定哪些目标 token 直接计分，因果掩码决定预测这些目标时能读取哪些输入位置。常见实现会将输入与目标错开一位；若移位做错，模型可能在输入中直接看到被考查的答案。

    \label{fig:SFT监督位置}
\end{figure}

从行为克隆（behavior cloning）的视角，SFT 告诉模型``遇到这里，示范者这样走''。示范由外部给定，在本书的宽泛用法中属于异策略（off-policy）数据；它与学生当前生成的路径可能不同。它没有显式要求模型在多个候选中评判哪个更好。可我们也不能说它绝对学不到判断：若数据里包含批改、比较和自我纠错示范，模型同样可以学习这些行为。真正的区别是，普通最大似然并未直接优化独立的偏好比较或环境回报。

训练后，小助开始稳定给出分步答案。我们很高兴，却先在验证集核对：是否只学会了固定套话？是否每题都添加无意义检查？是否在资料不足时照样编造？格式是容易观察的进步，任务能力与可靠性还需要分别检查。

\textbf{本节相关资料}
\begin{enumerate}
    \item Ouyang 等，2022，\href{https://arxiv.org/abs/2203.02155}{InstructGPT} 。阅读重点：监督示范在整个反馈训练管线中承担什么作用。
    \item Wei 等，2021，\href{https://arxiv.org/abs/2109.01652}{Finetuned Language Models Are Zero-Shot Learners}，FLAN 。阅读重点：任务多样性如何帮助指令泛化。
\end{enumerate}

\section{SFT 数据工程 模板与监督位置}\label{SFT 数据工程 模板与监督位置}

我们准备扩充 SFT 数据。最容易的做法是搜集尽可能多的问答，却发现质量逐渐失控：有的答案只给数字，有的先闲聊，有的把推理写错，有的缺少轮次结束标记。模型会同时拟合这些差异，我们不能把它们都归结为``数据越多越好''。

我们先规定示范质量。方程题要求步骤正确、足够解释且不编造定理；资料题要求引用可找到、依据能支撑回答；信息不足题要求说明缺少什么。我们保留不同的表达方式，避免把多样性误当成噪声，但不保留彼此矛盾的任务要求。数据清洗因此不仅是去重，还包括明确我们希望稳定出现的行为。

训练前，我们随机抽取已 token 化的样本，检查角色边界、监督位置、最大长度与结束标记。若长样本总在最终答案之前被截断，小助就可能学会漫长推演，却学不到收束推导。

我们也会看分项损失。固定模板词频很高，模型很快学会``下面分步骤说明''，总 loss 因此下降，但真正关键的算术 token 改善有限。这不表示格式一定``劫持''了学习，而是平均指标掩盖了不同位置的难度与价值。我们把格式正确率、答案正确率、步骤有效率并列，防止只优化最容易的一项。

计算资源有限时，我们可以使用低秩适配（Low-Rank Adaptation，LoRA）。它冻结大部分基础权重，用低秩增量表达参数更新，减少可训练参数和优化状态。LoRA 解决的是适配成本与参数化方式，不会自动修复坏数据，也不保证没有遗忘。秩（rank）、作用模块、学习率和数据量仍需要验证。全参数微调也并非总优于 LoRA，比较应在清楚的预算和任务下进行。

第一次小规模训练，我们故意让模型在少量干净样本上过拟合。若连这一步都做不到，先查管线；若可以学会，再扩大数据，观察泛化。这是一个前期测试，不是最终评估。任何系统性工程任务都需要预实验，对模型的上限和下限都有所了解。

\textbf{本节相关资料}
\begin{enumerate}
    \item Zhou 等，2023，\href{https://arxiv.org/abs/2305.11206}{LIMA Less Is More for Alignment} 。\textbf{阅读重点：高质量少量示范数据的训练价值可能非常大；但是也不要认为``少量数据总是足够''。}
    \item Hu 等，2021，\href{https://arxiv.org/abs/2106.09685}{LoRA Low-Rank Adaptation of Large Language Models} 。（务必理解LoRA原理）\textbf{阅读重点：低秩更新节省了哪些资源，又没有保证哪些能力。即便不看论文原文也建议找资料理解 LoRA 如何高效训练。}
\end{enumerate}

\section{续训退化 新任务变好为何旧能力变差}\label{续训退化 新任务变好为何旧能力变差}

小助已经会耐心讲题，我们想加入一门新课程，于是准备一批领域问答继续 SFT。为了节省标注，答案几乎都是一句话：``答案是 5。''\,``定义见第三章。''\,``选择 B。''新课程题的分数上升了，但小助对旧题也开始只给结论，不愿解释。

小助可能仍然有能力解释这些问题，只是在新训练分布下更偏向简短回答；也可能失去了某些步骤能力，这就是``灾难性遗忘''\footnote{灾难性遗忘是指这种现象：一个经过后训练的大模型在各方面能力达到均衡，此时用一个专项领域数据继续 SFT，导致其他各方面能力明显下降。这是许多任务里面需要考虑的问题。}；也可能是对话模板变了（一般不太可能出现这种失误）。

更新为什么会波及旧任务？不同任务共享大量参数。新数据的梯度鼓励短答案，可能降低长解释的概率；新领域的词汇、格式、难度与采样比例，也会重新分配训练权重。这些改变并不局限在新题的专属区域。

训练强度同样关键。相同的新数据，较高学习率、更多轮次、较窄覆盖，可能造成更大的参数漂移。反过来，过低学习率也可能学不到新增任务。我们不能只说``把学习率调小''，而要在新任务收益和旧任务保留之间做曲线比较，用实验结果来验证猜想。

我们把旧评估拆成两种：正常提问，以及明确要求``逐步解释并检验''的提问。若后者大幅恢复，可能主要是回答行为变化；我们还可以给模型提供正确的推理的开头，如果模型仍无法完成任务，那么有可能新的训练已经损害了模型本身的能力。

MiniMax 的稀疏 token 案例为我们补充了一个具体假设：后训练前后，输入嵌入变化较小，而某些低频 token 的 LM head 向量发生偏移；它们仍可能被输入侧利用，却更难作为输出生成。研究团队报告，加入词表覆盖数据能改善其测试案例。

这时我们也重新考虑方法的选择。若希望模型掌握经常变化的课程规则，采用RAG 方法也许比把每条规则写（训练）进权重更合适；若要长期改变模型的语言风格，SFT 更直接。继续训练之前，我们必须明确目标：希望模型新增知识还是改变行为，或者想都实现。

\textbf{本节相关资料}
\begin{enumerate}
    \item Kalajdzievski，2024，\href{https://arxiv.org/abs/2401.05605}{Scaling Laws for Forgetting When Fine-Tuning Large Language Models} 。阅读重点：微调收益与原能力保留如何随训练条件变化。
    \item Wu 等，2023，\href{https://arxiv.org/abs/2310.00492}{From Language Modeling to Instruction Following Understanding the Behavior Shift in LLMs after Instruction Tuning} 。阅读重点：指令微调前后的行为变化应如何测量。
    \item MiniMax Research，2026，\href{https://www.minimax.cn/blog/sparse-token-forgetting-investigation}{稀疏 Token 遗忘排查记录}，研究博客 。阅读重点：对照预训练与 SFT 的输入嵌入、输出头，并用覆盖数据验证修复方向。
\end{enumerate}

\section{遗忘诊断 用对照实验选择修复方法}\label{遗忘诊断 用对照实验选择修复方法}

我们决定回到续训前的同一个检查点\footnote{检查点一般是指之前的模型权重，每一个训练阶段都会保留一些检查点方便回溯，因为最新的训练可能出现问题}，做几组可比较的实验。A 组只用新课程数据；B 组加入一部分旧任务示范；C 组保持 A 的数据而降低训练强度；D 组改善新课程示范，让它们包含必要讲解。每组只改变明确的一项，先避免同时换模型、模板、数据和学习率。在实际工作里面要定位具体的问题通常就需要这样做许多组实验来观察。

比较混合数据时，一个细节很容易破坏结论。若 B 组训练 token 更多，它的优势可能来自额外计算；若固定总 token，新领域数据暴露量又会减少。我们要说清比较回答的是哪一个问题：相同总计算下如何分配数据，还是相同新数据暴露下保留旧能力的成本是多少。最好分别报告，而不是把两个问题混成一个排名。

我们记录一组教学用结果：A 新领域提高最多、旧讲解下降明显；B 新领域略有改善、旧能力保留较好；C 退化较少，但新增知识也没学牢；D 同时改善讲解和新题。它们不证明混合数据或低学习率普遍有效，却告诉我们，这次数据风格与更新强度都可能参与了退化。

接下来我们检查失败样本。如果旧题的最终答案正确、解释变短，补充讲解示范可能有针对性；如果新题使用旧规则，可能需要更明确的领域条件；如果所有长回答都提前停止，则先查结束标记。修复手段必须与已观察到的缺陷相对应。

我们可以加入回放数据，保存代表性旧任务；也可以在旧输入上约束模型与参考模型的分布距离，或使用老师给出反馈。约束只能在我们检查的输入上发挥作用，不能保证保留全部能力。新旧目标若本身冲突，也不存在无成本的完美保留，我们需要依据实际使用需求确定取舍。

这一轮工作形成了后面反复使用的节奏：发现退化，分解指标，提出假设，设计单变量对照，检查样本，再扩大实验。我们不再把模型训练当作不停尝试超参，而是把它当作一个可以逐步排除解释的研究过程。

\textbf{实践} 参考一些开源学习项目，在服务器上用 LoRA 方法 SFT 后训练一个 Qwen 小模型，观察训练前后模型的某些能力是否像预期一样变化。
