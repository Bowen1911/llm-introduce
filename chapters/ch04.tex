\chapter{监督微调与续训退化}\label{监督微调与续训退化}

前面几章介绍了语言模型怎样预测文本，以及文本怎样变成可供计算的表示。现在，我们开始真正训练学习助手“小助”。它已经读过大量文本，能够续写一道题、模仿一段讲解，却还需要学习怎样根据学生的要求组织回答：什么时候直接给出结论，什么时候展开步骤，怎样接着上一轮对话继续解释。

监督微调是完成这一步的基本方法。我们先准备一批希望小助模仿的示范，再通过训练提高这些回答的概率。随着训练推进，一个新的问题也会出现：小助在新课程上进步了，原来擅长的讲题、阅读理解或其他语言的回答却变差了。本章沿着这条过程，依次说明微调的目标、数据与参数更新，再深入讨论灾难性遗忘，以及怎样在学习新任务的同时保留旧能力。

\section{监督微调 SFT 用示范塑造助手行为}\label{监督微调 SFT 用示范塑造助手行为}

\subsection{从一道题理解训练样本}

回到最初的方程题。学生问：“请解方程 $3(a+2)=21$，并说明每一步为什么这样做。”我们给小助准备如下示范：

\begin{quote}
先把等式两边同时除以 3，得到 $a+2=7$。再把两边同时减去 2，得到 $a=5$。最后代回原式：$3\times(5+2)=21$，等式成立，所以答案是 $a=5$。
\end{quote}

这条数据由两部分组成：前面是学生的问题，后面是我们希望助手给出的回答。监督微调（Supervised Fine-Tuning，SFT）让模型在看到问题后，更倾向于生成这样的回答。训练中反复出现正确的求解、解释和检验，模型就有机会把这些行为推广到新题上。为了让它学会如何处理一类问题，我们还要提供不同数字、不同题型和不同提问方式的示范。

SFT 沿用了第二章的下一个词元预测目标。变化主要发生在训练材料和监督位置上：预训练使用广泛文本学习语言与知识，助手的 SFT 则把指令、上下文和合适的回应组织在一起，集中训练我们需要的行为。示范既可以由人编写，也可以由其他模型生成后审核。示范中的解题过程、回答长度、表达方式和错误，都会成为模型学习的对象。

\subsection{模型怎样学习一整段回答}

训练时，模型逐个预测示范回答中的 token。预测“得到 $a=5$”时，前面的题目和正确推导都已经作为输入提供给它。这种使用标准答案前缀来预测下一个 token 的做法，称为教师强制（teacher forcing）。借助因果注意力掩码，一段回答中各位置的预测可以在同一次前向计算中完成，同时保持每个位置只能读取它前面的内容。

例如，示范被简化为“答案是 5”。模型要学习在问题之后预测“答”，在问题和“答”之后预测下一个 token，再沿着示范继续预测。这里的切分只是帮助理解；实际 token 边界由分词器决定。如果模型给正确 token 的概率较低，损失就较大，训练会调整参数来提高这个概率。

真正回答学生时，模型接收到的是自己刚刚生成的前缀。假如第一步算错，后面就要沿着这个错误继续生成，而训练中的标准解答通常没有覆盖这条路径。因此，训练集上的回答已经很容易预测之后，我们还要让模型在留出的题目上完整生成，查看它能否独立完成求解。包含常见错误与修正过程的示范，也能帮助它学习遇到错误时怎样继续。

从行为克隆（behavior cloning）的角度看，SFT 是向示范者学习“在这个上下文中，下一步怎样做”。解题、批改、比较两个解法，都可以写成示范。后面章节将介绍另一类训练方式：让模型先尝试，再根据尝试结果获得反馈。

\subsection{损失掩码决定哪些位置接受监督}

一条对话输入中通常还包含系统要求、用户问题和角色标记。训练助手时，我们一般把系统要求和用户问题作为条件，只对助手回答计算预测损失。损失掩码（loss mask）就是用来标记这些位置的：参与监督的位置记为 1，其余位置记为 0。

设拼接后的序列为 $x_1,\ldots,x_T$，模型参数为 $\theta$，位置 $t$ 的掩码为 $m_t$。对一条样本，可以把 SFT 损失写成：
\[
L_{\mathrm{SFT}}(\theta)
=-\frac{1}{\sum_{t=1}^{T}m_t}
\sum_{t=1}^{T}m_t\log p_{\theta}(x_t\mid x_{<t}).
\]

$x_{<t}$ 表示目标 token 前面的所有内容。右边先计算每个目标的负对数概率，再对有效监督位置求平均。正确 token 的概率越高，这一项损失越小。假如样本中有 100 个位置，其中 60 个属于需要学习的助手回答，分母就是 60。数据处理时需要确保每条训练样本至少保留一个有效监督位置。

图 \ref{fig:SFT监督位置} 展示了一个简化例子。用户问题虽然不直接计入损失，模型在回答时仍要读取它；回答的损失也会通过这条计算路径影响可训练参数。因而，把问题位置的损失设为 0，表示我们没有要求模型学习生成这个问题。

这里还涉及另一个掩码：因果注意力掩码。它负责限制信息的流动，使预测 $x_t$ 时只能使用 $x_{<t}$。损失掩码则负责选择哪些预测计入训练目标。实现时，输入与目标通常错开一位：读到某个位置的输入后，预测下一个位置的 token。把这两件事分别检查清楚，就能知道模型“看到了什么”和“正在学习预测什么”。

\subsection{多轮对话怎样进入训练}

学生拿到方程的解答后，又问：“为什么可以把两边同时除以 3？”这时，小助的回答需要用到上一轮题目和求解过程。一条完整的多轮训练样本可以依次放入用户问题、助手回答、用户追问和助手解释，并在两个助手回答上都计算损失。因果掩码保证第一轮回答读不到后面的追问，第二轮回答则能利用前面的全部对话。

另一种组织方式是把它拆成两条样本。第一条训练第一轮回答；第二条包含完整的历史对话，但只监督最后一轮解释。两种方式都能训练多轮能力，区别在于哪些回答被计入损失、同一段内容被学习了多少次。选择实现方式后，可以把处理完的样本解码成文本，并标出监督位置，直接检查每一轮的上下文是否完整。

\begin{enumerate}
    \item Ouyang 等，2022，\href{https://arxiv.org/abs/2203.02155}{Training language models to follow instructions with human feedback}。即 InstructGPT。阅读重点：监督示范怎样把预训练模型引向助手行为。
    \item Wei 等，2021，\href{https://arxiv.org/abs/2109.01652}{Finetuned Language Models Are Zero-Shot Learners}。即 FLAN。阅读重点：把多种任务写成指令后，模型怎样学习在未见任务上遵循要求。
\end{enumerate}

\section{SFT 数据工程 从示范到可训练的序列}\label{SFT 数据工程 模板与监督位置}

\subsection{让回答方式与任务要求对应起来}

我们开始扩充数据。有的学生只想核对答案，有的学生需要从头学习，有的学生已经做了一半，只想知道错在哪里。这三种需求适合不同的示范：核对答案可以简短，初次学习需要解释，检查错误则要围绕学生已有的步骤展开。把这些场景写进指令，模型才能学习何时采用哪种回答方式。

例如，“只给出 $a$ 的值”可以对应“$a=5$”；“请向初学者解释解题过程”则对应完整推导。两种样本可以同时保留。真正需要清理的是错误推导、遗漏必要条件、答非所问，以及任务要求与答案不一致的样本。对于同一个开放问题，存在几种合理表达也很正常，多样的措辞能够帮助模型适应真实用户。

如果数据大量混用长篇讲解和极简结论，却很少在问题里说明需求，模型就只能从有限线索中猜测回答长度。解决办法是补充清楚的任务条件，并根据实际使用场景调整样本比例。损失或梯度范数突然上升时，应回到对应批次查看长度、难度、标注和数值状态；仅凭风格不同，还不足以定位训练异常的原因。

\subsection{模板、结束标记和截断会改变学习内容}

人看到的是一组对话消息，模型实际接收的是一条 token 序列。对话模板（chat template）负责把系统、用户和助手消息转成模型约定的角色标记和文本排列。训练与使用时采用一致的模板，小助才能在熟悉的位置识别“现在轮到助手回答”。

结束标记同样是示范的一部分。模型需要学习何时结束本轮回答，等待学生追问。如果答案后面漏掉结束标记，或者把它放进解题过程的中间，训练就会给出错误的停止信号。检查一条样本时，我们应当能从序列中读出清楚的角色边界、回答起点和回答终点。

最大序列长度则决定哪些内容最终能进入训练。假设问题和资料占用了大部分空间，长回答在“因此答案是”之前就被截断，模型学到的主要是前半段推导。大量这样的样本会让它缺少完成回答的示范。可以根据任务选择缩短资料、重新组织样本或增加序列长度，并统计截断发生在问题、推导还是最终答案的位置。处理完以后还要检查有效监督 token 数，及时移除回答已被全部截掉的样本。

\subsection{数据配比决定模型把精力花在哪里}

样本条数只描述了数据量的一部分。100 条一句话回答和 100 条长篇推导，包含的监督 token 数可能差很多。如果训练按全部有效 token 求平均，较长的回答就会贡献更多损失项。若训练先对每条样本取平均，再对样本取平均，则是另一种权重分配。理解具体实现，才能解释某类数据实际占了多大训练比重。

因此，我们既统计任务类别的样本数，也统计有效监督 token 数。例如，新课程问答占了九成监督 token，旧课程讲解只占一成，模型接受到的训练信号自然更偏向新课程。即使文件中两类样本的条数接近，这种偏向仍然可能存在。后面讨论数据回放时，还会用到这个区别。

数据质量也可以从训练后的行为反查。模型很快学会“下面分步骤说明”这样的高频开头，总损失随之下降；但要知道它是否学会解题，还需要单独检查答案、推导和检验。在资料问答中，则要查看回答是否真正使用了给定材料。把这些任务结果与总损失放在一起看，我们才能知道进步发生在哪里。

\subsection{先让一个小实验完整跑通}

第一次训练可以从少量经过人工检查的样本开始。先确认模型能够明显降低这些样本上的损失，并生成与示范接近的回答。这一步是在检查数据处理、监督位置、参数更新和模型保存是否连通。若训练很久仍学不会几十条简单样本，就值得先查看实际输入、标签和可训练参数。

管线跑通之后，再加入没有参与训练的验证题，逐步扩大数据。验证题要覆盖任务类型、难度和回答长度，近重复题应尽量分在同一侧，避免训练集中的换词版本进入验证集。到了这一步，我们才开始比较不同数据配比和训练设置带来的泛化效果。

\section{全参数微调与 LoRA 参数怎样发生变化}\label{全参数微调与LoRA}

\subsection{全参数微调更新整个模型}

SFT 规定了模型向什么示范学习，接下来还要决定允许哪些参数更新。全参数微调（full fine-tuning）允许更新模型的全部参数。它可以广泛调整输入表示、Transformer 各层和输出层，适合需要充分适应新数据的训练任务。

这种灵活性也有资源成本。训练除了保存模型权重，还要保存梯度、优化器状态以及反向传播所需的中间结果。以 Adam 一类优化器为例，每个可训练参数还对应跟踪梯度变化的状态。当模型达到数十亿参数时，这些额外存储往往占用大量显存。

如果我们只想让小助适应某门课程，可以尝试用更少的可训练参数表达这次改动。低秩适配（Low-Rank Adaptation，LoRA）就是一种常用做法。

\subsection{用两个小矩阵表达权重增量}

考虑模型中的一个线性变换 $y=W_0x$，其中 $W_0$ 有 $d_{\mathrm{out}}$ 行、$d_{\mathrm{in}}$ 列。LoRA 冻结原来的 $W_0$，另加两个可训练矩阵 $A$ 和 $B$，用它们的乘积表示更新量：
\[
W_{\mathrm{eff}}=W_0+sBA,
\qquad
y=W_0x+sB(Ax).
\]

$A$ 的形状是 $r\times d_{\mathrm{in}}$，$B$ 的形状是 $d_{\mathrm{out}}\times r$，$s$ 是缩放系数。中间维度 $r$ 称为秩参数，通常远小于输入和输出维度。可以把计算理解为：先通过 $A$ 把输入变成一个较小的向量，再通过 $B$ 产生对原输出的修正。训练主要调整这两个小矩阵，从而学习需要的修正方式。

原矩阵共有 $d_{\mathrm{out}}d_{\mathrm{in}}$ 个参数，两个新矩阵合计只有 $r(d_{\mathrm{in}}+d_{\mathrm{out}})$ 个参数。例如，对一个 $4096\times4096$ 的矩阵，原来约有 1678 万个参数；当 $r=8$ 时，LoRA 增量只有 65536 个参数，约为原来的 $0.39\%$。这个计算解释了为什么 LoRA 能显著减少梯度和优化器状态的存储。

模型仍然需要执行原网络的计算，并把梯度传到需要训练的增量参数，因此训练总显存和计算时间不会按上述参数比例一起缩小。实际节省多少，还取决于序列长度、批大小、插入 LoRA 的模块，以及训练框架的实现。

\subsection{冻结基础权重以后，为什么还会遗忘}

LoRA 保留了原始权重，但启用适配器后，模型实际使用的是 $W_0+sBA$。只要这个有效权重改变，隐藏状态和输出概率就会改变。即使增量的秩很小，它也可能作用于多种任务共用的计算方向，影响旧题的求解与表达。

因此，LoRA 的低秩限制可以控制更新的形式，却没有直接告诉模型哪些旧行为需要保留。在一些任务中，它能以较小改动完成适配；在另一些任务中，长时间训练或较强的更新仍会带来明显退化。Kalajdzievski 对语言模型微调的研究也观察到了启用 LoRA 后的遗忘现象。选择 LoRA 时，我们仍然要测量新任务收益和旧任务表现。

如果基础权重保持原样、适配器没有合并进去，关闭适配器就能恢复原来的参数配置。这对版本管理和不同课程之间的切换很有用。启用适配器后是否同时保有新旧能力，则需要另外评估。若产品要求一个助手同时回答所有课程，训练数据中就需要体现这种综合要求。

在实践中，可以先选择一组目标模块和秩，建立能够跑通的 LoRA 基线，再调整学习率、训练量和数据配比。全参数微调和 LoRA 都需要与各自的设置配套比较：同一个学习率对两种参数化方式可能产生不同强度的更新。

\textbf{本节相关资料}
\begin{enumerate}
    \item Hu 等，2021，\href{https://arxiv.org/abs/2106.09685}{LoRA: Low-Rank Adaptation of Large Language Models}。阅读重点：低秩增量的结构、参数数量，以及训练和部署时怎样使用增量。
    \item Kalajdzievski，2024，\href{https://arxiv.org/abs/2401.05605}{Scaling Laws for Forgetting When Fine-Tuning Large Language Models}。阅读重点：LoRA 训练中的任务收益与遗忘怎样共同变化。
\end{enumerate}

\section{灾难性遗忘 新任务变好为何旧能力变差}\label{续训退化 新任务变好为何旧能力变差}

\subsection{遗忘是相对于续训前的能力而言的}

小助已经能稳定讲解旧课程，我们现在加入一门新课程。新数据主要是选择题和术语问答，答案经常只有“选择 B”或一句定义。继续 SFT 后，新课程成绩上升了，但旧课程的回答出现了变化：有的题只剩一个结论，有的题开始漏掉步骤，还有的题连明确要求检验时也算不对。

模型在学习新任务的过程中，先前学会的任务表现明显下降，这种现象称为灾难性遗忘（catastrophic forgetting）。它广泛出现在神经网络的持续学习中：模型依次接触不同任务，后来的训练会影响前面的学习成果。在大语言模型中，受影响的既可能是预训练获得的知识和语言能力，也可能是此前后训练形成的讲解、指令遵循和工具使用能力。通常的解释是模型原本的行为分布出现比较大的漂移。

测量遗忘要有一个明确的起点。假设在一组固定的旧题上，续训前正确率为 $86\%$，续训后为 $70\%$，我们就观察到了 16 个百分点的下降。这里的数字只是演示比较方法。实际还应查看下降集中在哪些题型，并用足够数量的题目和一致的生成设置确认结果。

遗忘与过拟合关注的对象不同。过拟合常表现为新任务训练集越做越好，新任务验证集却没有相应进步；遗忘关注的是旧任务相对于续训前的下降。一次微调中，这两种现象可以同时出现，也可以只出现一种。例如，新课程验证集确实进步了，旧课程仍可能退化。

\subsection{共享参数让新旧任务相互影响}

要理解遗忘，可以先看训练目标里有什么。只使用新课程数据时，每一次更新都在努力降低新课程的损失。旧课程的求解与讲解没有出现在当前训练目标中，优化器也就没有收到“请同时保持旧题表现”的直接信号。

与此同时，模型的参数由许多任务共同使用。处理方程题、总结文章、解释新课程定义，都会经过大量相同的注意力层和前馈层。为了更好地输出新课程中的短答案，训练可能改变回答长度的倾向、某些词的概率，以及组织推导时使用的中间表示。这些改变也会作用到旧课程。

用梯度的语言说，不同任务希望参数移动的方向有时相近，有时相互冲突。方向相近时，新任务训练还能帮助旧任务，这称为正迁移；方向冲突时，一次有利于新任务的更新可能增大旧任务损失。如果训练持续沿着新任务的方向前进，旧任务的损害就可能逐步积累。

这解释了为什么数据少也可能造成明显遗忘。关键还包括这些数据被重复训练了多少遍、与原任务分布相差多大，以及每次更新有多强。一批高度单一的示范反复出现，会持续推动模型适应这一种任务。模型并没有收到明确指令去删除旧知识，旧表现是在共享参数被重新调整的过程中发生了变化。

\subsection{回答习惯变化与任务能力下降怎样区分}

旧题的答案变短，首先说明默认输出方式变了。为了看清变化发生在哪一层，我们可以对续训前后的模型使用同一批题，分别设置三种提问条件。以 $3(a+2)=21$ 为例：

\begin{enumerate}
    \item \textbf{普通提问：}“请解这个方程。”观察模型默认采用什么回答方式。
    \item \textbf{明确要求：}“请逐步求解，并把答案代回原式检验。”观察相关能力能否被直接指令调动。
    \item \textbf{提供起步：}“先把两边除以 3，得到 $a+2=7$。请继续求解并检验。”观察模型能否在给定正确起点后完成后续步骤。
\end{enumerate}

如果普通提问时只给结论，明确要求后却仍能完整、正确地解释，优先处理的是回答习惯：补充不同需求下的示范，让模型重新学会何时展开。若只有提供起步以后才能完成，排查重点就移到如何选择第一步、如何组织完整求解过程。若续训前能做好的题，在三种条件下都出现大量步骤错误，就需要重点检查任务能力的退化。

这组对照让我们把“变差了”变成可操作的问题。记录时分别统计最终答案、步骤正确性和检验有效性，还可以记录回答长度。同一道题的一次成功可能来自采样波动，因此应比较一批题的表现；对话模板、提示条件和生成长度也要在续训前后保持一致。若回答恰好被长度限制截断，先调整评估管线，就能避免把未生成完的解答计成遗忘。

\subsection{低频词元为何可能逐渐难以生成}

遗忘还可能集中在输出层。模型预测下一个 token 时，输出头（language modeling head，LM head）根据当前隐藏状态，为词表中的每个 token 计算一个分数，再用 softmax 转成概率。训练提高正确 token 的概率，也会改变它与其他候选之间的竞争关系。

一个 token 即使没有在本次答案中出现，仍然参与了 softmax 的归一化。对于单个目标 token 的交叉熵损失 $\ell$，设正确答案为 $y$，候选 $j$ 的分数为 $z_j$，概率为 $p_j$，则有：
\[
\frac{\partial \ell}{\partial z_j}
=p_j-\mathbf{1}[j=y].
\]

这里的 $\mathbf{1}[j=y]$ 在 $j$ 为正确答案时取 1，其余时候取 0。如果把各个分数看作直接可调的量，正确 token 对应的导数为 $p_y-1$，梯度下降会推动它的分数上升；其他 token 对应的导数为 $p_j$，更新方向则是降低它们在当前上下文中的分数。实际训练会把这些信号继续传回共享参数。这个式子解释了为什么很少作为正确答案出现的 token，仍然会受到训练影响。

当某些低频 token 长期很少得到正向监督时，它们的生成行为可能逐渐变化。如果输出头参与训练，其参数可以直接受到影响；即使输出头被冻结，上游隐藏状态的变化也会改变最终分数。因此，排查具体问题时，需要一起看数据覆盖、输出概率和相关参数的变化。

MiniMax 在 2026 年公布过一个具体案例：模型能够回答与“马嘉祺”有关的信息，却在被问到队长姓名时难以输出“嘉祺”。在该模型的词表中，“嘉祺”是一个独立 token，后训练数据中包含它的样本很少。团队对比参数发现，输入嵌入变化较小，而对应输出头向量发生了明显偏移。

团队随后混入覆盖词表的合成重复数据，让这些 token 重新有机会作为生成目标，并报告姓名回答和部分复制任务得到改善\footnote{案例来源：MiniMax Research，2026，\href{https://www.minimax.cn/blog/sparse-token-forgetting-investigation}{为什么 MiniMax 大模型不认识“马嘉祺”？稀疏 Token 遗忘排查记录}。}。这个案例提供了一条具体的排查路线：从生成失败出发，检查分词与数据频率，再对比输入和输出两端，最后用补充训练信号验证修复方向。

\subsection{训练强度决定模型向新分布移动多远}

学习率控制每次更新的步幅，训练步数决定更新发生多少次，数据配比则决定这些更新主要服务于哪些任务。它们共同影响新任务适应和旧能力保留。对于同一份数据，较大的学习率或更多轮训练，往往会让模型更快、更充分地向新分布移动，也更需要关注旧任务的变化。

这里没有一个适用于所有模型的固定学习率。全参数微调和 LoRA 的参数化方式不同，批大小、优化器、训练规模也会改变合适的设置。比较时可以从已有训练配置出发，设置几档学习率，并沿训练过程保存检查点。检查点（checkpoint）就是某个训练时刻保存的模型及相关状态。

把每个检查点的新旧任务成绩画在一起，就能看到训练过程中的取舍：有时前半程新任务快速进步，旧任务基本稳定；后半程新任务收益已经很小，旧任务还在下降。这样的结果提示我们选择较早的检查点，或者改变数据与约束，再继续训练。仅把学习率降低而无限延长训练，仍可能累积明显变化。

    \item Kalajdzievski，2024，\href{https://arxiv.org/abs/2401.05605}{Scaling Laws for Forgetting When Fine-Tuning Large Language Models}。阅读重点：训练步数、可训练参数量与遗忘的关系。

\section{缓解遗忘 让旧能力继续参与训练}\label{缓解灾难性遗忘}

\subsection{数据回放给旧任务保留训练信号}

最直接的办法是在新课程训练中继续放入旧任务示范。这种重新使用过去任务数据的做法叫作回放（replay）。每个阶段的训练既告诉模型“怎样回答新问题”，也继续强化“旧问题仍然要这样回答”。

设新任务损失为 $L_{\mathrm{new}}$，回放数据上的损失为 $L_{\mathrm{old}}$，一个简单的联合目标可以写成：
\[
L_{\mathrm{mix}}
=(1-\rho)L_{\mathrm{new}}+\rho L_{\mathrm{old}},
\qquad 0\leq\rho\leq1.
\]

$\rho$ 控制旧任务信号的权重。它越大，优化时越重视保留旧任务；在固定训练预算下，留给新任务的份额也越少。如果两类损失都按有效监督 token 取平均，那么按相应 token 比例混合数据，可以实现这种加权思路。实践中应同时记录采样方式和损失归一化方式，让设定的比例与实际权重对应。

回放集应覆盖我们希望保留的行为。小助要继续讲题，就需要分步求解和解释的示范；要继续根据材料回答，就需要阅读与引用的示范；要保留多语言能力，就需要相应语言的数据。只回放简单算术，给长文理解提供的保护就很有限。选择时还要兼顾难度、长度和容易退化的少见场景。

旧数据不足时，可以让续训前的模型或其他可靠教师在代表性问题上生成回答，再审核、筛选成回放样本。这称为生成式回放。它降低了重新标注的成本，数据覆盖和答案质量则取决于问题设计与筛选。对于教师本来就会答错的题，我们应提供修正后的示范，让模型保留有用能力并改进已有错误。

\subsection{用参考模型保留旧场景中的输出行为}

除了完整示范，我们还可以保留续训前的模型，把它冻结为参考模型。对同一段旧任务上下文，参考模型和正在训练的模型分别预测下一个 token。我们在新任务损失之外，再加入一项约束，让两者的预测分布保持接近。

例如，在“先把两边除以 3，得到”之后，原模型可能给几种正确表述较高概率。仅用一条文字示范训练，会强调其中一种写法；比较整个预测分布，则能传递更细的候选关系。常见做法用 KL 散度衡量分布差异，并用一个系数控制这部分损失的强度。第五章会介绍 KL 约束，第六章会进一步展开这种利用教师分布的知识蒸馏。

使用这一方法，需要决定在哪些上下文上比较分布。保留数学讲解，就应包含相应解题前缀；保留其他语言，就需要相应语言的上下文。约束只能在提供的场景中直接发挥作用，所以代表性数据仍然重要。

代价是训练时要额外计算参考模型的输出，或提前存储所需的概率信息。约束过强会限制新任务学习，也会让模型更难修正原有错误。因此，我们可以在需要保留的旧场景上施加约束，同时用正确的新示范引导目标变化，再比较不同约束强度下的新旧任务成绩。

\subsection{限制参数变化，或为不同任务保留适配器}

另一类方法直接约束参数更新。一种直观做法是在训练目标中加入惩罚：参数偏离续训起点越远，额外损失越大。弹性权重巩固（Elastic Weight Consolidation，EWC）进一步区分参数对旧任务的重要程度，对估计更重要的参数施加更强约束。它体现了一个持续学习思路：把保留旧任务的要求写进优化目标。

在大型语言模型中，估计和存储参数重要性需要成本，而限制参数移动也会影响新任务的适应空间。实际选择时，可以先从数据回放和更新强度入手，再根据资源与任务考虑更复杂的参数约束。

冻结部分层、使用 LoRA，也是在限制允许变化的部分。如果新旧任务可以明确区分，还可以为每门课程保留独立适配器，回答时加载对应版本。这让各课程的训练增量分开保存，适合任务边界清楚的场景。代价是系统需要识别任务、管理多个版本；跨课程综合问答则还需要专门训练和评估。

\subsection{让修复方法对应具体的退化}

对于默认回答过短，可以先补充明确要求解释的示范，并保留只需结论的场景，让模型学习按需求调整长度。对于任务步骤错误，可以增加对应能力的回放、减弱过强的更新，并查看哪些检查点仍保有旧能力。对于低频词元生成失败，则可以检查其作为目标的覆盖度，补充经过验证的复制、使用或问答样本。

有时，新旧任务的要求本身需要重新组织。例如，同样是“请解这道题”，一批数据要求只输出选项，另一批要求完整推导。可以在输入中标出“答题模式”和“讲解模式”，让模型依据明确条件选择行为。这样做既使示范更容易学习，也让最终输出更可控。

还有一些新增内容适合由外部资料提供。课程规则经常更新时，可以在第八章介绍的检索增强生成（RAG）系统中维护规则，让模型根据检索结果回答；需要长期形成稳定的解释方式和工具使用习惯时，SFT 则能直接提供行为示范。把知识更新与行为训练安排在合适的位置，可以减少不必要的反复续训。

\begin{enumerate}
    \item Rolnick 等，2019，\href{https://arxiv.org/abs/1811.11682}{Experience Replay for Continual Learning}。阅读重点：在持续学习中，保留过去经验怎样缓解遗忘；该文实验采用强化学习任务。
    \item Kirkpatrick 等，2017，\href{https://arxiv.org/abs/1612.00796}{Overcoming catastrophic forgetting in neural networks}。阅读重点：EWC 怎样根据旧任务的参数重要性限制后续更新。
    \item Hinton 等，2015，\href{https://arxiv.org/abs/1503.02531}{Distilling the Knowledge in a Neural Network}。阅读重点：教师的概率分布怎样成为比单个答案更细致的训练信号。
\end{enumerate}

\section{遗忘诊断 用一轮对照实验选择修复方法}\label{遗忘诊断 用对照实验选择修复方法}

\subsection{先建立能够反复比较的起点}

现在把前面的知识用到一次完整实验中。假设小助学完新课程以后，旧课程讲解明显变差。我们保留续训前的检查点，从这个共同起点启动各组实验。这样比较时，每组经历的新增训练都有清楚的记录。

准备数据时，分别保留新课程和旧课程的训练、验证样本。新课程验证集检查新增任务是否学会，旧课程验证集检查原有能力是否保留。回放使用旧课程训练样本，验证题留在训练之外。开发时用这些验证集选择方案，最后再用独立测试题检查选定模型。

对于旧课程，我们沿用普通提问、明确要求解释、提供起步提示这三类条件，分别记录答案正确率、步骤正确性和检验是否有效。评估脚本固定对话模板、采样设置和生成长度上限，并保存具体回答。这样出现分数变化时，我们能回到同一道题查看差别。

\subsection{每组实验回答一个具体问题}

第一轮可以设置下面四组。它们分别检查原方案、数据覆盖、更新强度和示范方式的影响。

\begin{enumerate}
    \item \textbf{A 组：只用新课程数据。}保留原来的简短答案和训练设置，测量新任务收益与旧任务下降，作为后续比较的基线。
    \item \textbf{B 组：加入旧任务回放。}保持模板、优化器和学习率设置，按预先确定的比例加入旧课程示范，检查补充旧任务信号能保留多少能力。
    \item \textbf{C 组：降低学习率。}使用与 A 组相同的数据顺序、批大小和训练步数，只降低学习率，检查更新强度对新旧任务的影响。
    \item \textbf{D 组：补全新课程示范。}保留新课程题目，把需要讲解的答案补成经过审核的推导，检查示范方式改变后，模型能否恢复合适的讲解行为。
\end{enumerate}

数据变化会同时影响训练长度，因此预算需要提前约定。若比较固定资源下的方案，可以让 A、B 两组都训练 100 万个有效监督 token：A 组全用新任务，B 组分配 90 万给新任务、10 万给旧任务。这时 B 组的新任务曝光量相应减少，比较的是怎样分配同一份监督预算。

若更关心保留能力需要增加多少训练，可以让 B 组也学习 100 万个新任务 token，再额外加入 10 万个旧任务 token。这样两组的新任务曝光量一致，B 组使用了额外训练。两种设计分别回答资源分配和追加成本的问题。完整输入长度也影响计算量，所以还应记录总处理 token 数与训练耗时；D 组增加解释以后尤其需要记录这些变化。

\subsection{沿训练过程寻找合适的检查点}

我们在固定间隔保存检查点，同时评估新旧任务。假设 A 组持续提高新题成绩，旧题的步骤正确率却不断下降；B 组保留了更多旧题表现，说明回放值得继续调整。下一轮可以比较几个回放比例，观察增加旧数据会带来多少保留收益，以及新任务学习是否仍能达到要求。

如果 C 组的新旧任务变化都更小，降低学习率确实减缓了模型向新分布移动。接下来可以比较相近新任务成绩时，各组旧任务的表现，再决定采用哪个设置。这样能避免把“几乎没有学到新内容”误选成最好的保留方案。

如果 D 组恢复了详细讲解，还要检查增加的步骤是否正确。正确率和讲解质量一起恢复，才说明示范调整符合目标；仅仅字数增多，则需要继续清理推导或补充缺失的能力训练。若结果差别很小，可以扩大验证题集，或者更换随机种子重复训练，检查结论是否稳定。

实际选模型时，我们可以先规定可以接受的旧任务下降幅度，再在满足要求的检查点里比较新任务成绩。这个规则把“想兼顾新旧能力”变成了可执行的选择标准，也使停止训练的时机更清楚。

\subsection{结合训练曲线回查失败样本}

训练日志帮助我们找到问题出现的时刻。损失突然升高时，可以查看对应批次是否包含异常长样本、难题或错误标签；梯度范数突然升高时，可以连同学习率、数值精度和梯度裁剪一起检查。梯度范数（gradient norm）描述一次更新前梯度的整体大小，突增提供的是排查位置，具体原因仍要从数据和计算状态中确认。

生成结果提供另一组线索。回答反复重复同一句话，可以检查训练样本是否重复、结束标记是否正确，以及续训前后生成配置是否一致；回答总在中途停止，可以查看训练截断与最大生成长度；只有某类旧题退化，则应回到该任务的数据覆盖和失败步骤。这些检查把训练曲线与用户真正看到的回答连接起来。

\textbf{实践}~选择一个能够在现有设备上微调的小模型，先保存它在新旧两组留出题上的回答。使用 LoRA 分别训练“只用新数据”和“加入旧任务回放”两个版本，记录数据比例、有效监督 token 数、训练耗时和各检查点成绩。最后选出几道代表性失败题，对照训练前后的完整回答，解释你观察到的是回答习惯变化、步骤能力下降，还是数据处理问题。

完成这一轮之后，我们得到的应当是一个既能适应新课程、又保留必要旧能力的 SFT 模型。接下来，还会遇到另一种情形：面对较难的题，小助有时做对，有时做错。第五章将从这种多次尝试的差异出发，介绍采样、强化学习与偏好优化。
