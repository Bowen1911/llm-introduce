\chapter{可解释性入门}\label{可解释性入门}

\section{可解释性的证据 看到了什么与证明了什么}\label{可解释性的证据 看到了什么与证明了什么}

前面的训练诊断让我们发现：小助的回答变短，可能只是行为倾向变化；一个词生成不出来，也可能涉及输出端偏移。我们已经能通过输入与输出比较排除一些解释，但还会追问：模型内部到底利用了哪些信息，又通过什么计算形成这次答案？这就是可解释性（interpretability）要帮助我们研究的问题。

我们先区分两个尺度。行为分析改变提示、数据或工具，观察系统如何反应；机制可解释性（mechanistic interpretability）进一步研究参数、激活与计算路径，尝试用可检验的机制解释特定行为。解释的对象可以是一道题、一个注意力头，也可以是跨一批输入反复出现的计算模式。我们必须先写明解释范围，不能从一个例子跳到``整个模型就是这样思考的''。

最容易上手的是注意力热图。假设小助生成``她''时，一个头对某个人名分配较大权重，这是一条有价值的观察。但权重只描述该头怎样混合 value；value 的内容、输出投影、残差中的其他信息和后续层的计算同样影响答案。高权重不能单独证明``这个词导致了回答''，低权重也不能保证``这个词毫无作用''。

小助还可以自己解释：``我先根据代词找到人名，再回答。''我们把这种文字当成另一个需要验证的输出。它可能忠实，也可能遗漏影响因素，或者合理化一个已经偏向的答案。可见推理过程有教学和检查价值，却不能直接替代内部因果证据。

我们把证据分成三层：观察到某个激活与行为相关；从表示中读出某类信息；干预某处计算后，目标行为按预测改变。后两层也有各自的假设和局限。接下来，我们先学习怎样``读出''，再学习怎样做受控干预。

\textbf{停下来试一试} 对``模型注意到名字''\,``模型表示了人物关系''\,``这个头参与选择答案''三句话，分别写出需要什么证据。若三句都只拿同一张热图支持，我们还没有区分观察与因果。

\textbf{本节相关资料}
\begin{enumerate}
    \item Jain 与 Wallace，2019，\href{https://arxiv.org/abs/1902.10186}{Attention is not Explanation} 。阅读重点：注意力权重为什么不足以自动充当解释；不要反过来推成``注意力完全没有分析价值''。
    \item Turpin 等，2023，\href{https://arxiv.org/abs/2305.04388}{Language Models Don't Always Say What They Think Unfaithful Explanations in Chain-of-Thought Prompting} 。阅读重点：解释文本如何遗漏实际影响回答的因素。
\end{enumerate}

\section{线性探针 表示中能读出什么}\label{线性探针 表示中能读出什么}

我们怀疑小助在某一层已经表示了``谁把物品给了谁''，但最后没有选对人名。怎样判断信息是在中途丢失，还是存在却没有被后续计算有效利用？一种入门办法是在线性探针（linear probe）上做实验：冻结小助，只训练一个很小的读出器。

我们收集一批带标签的句子，取指定层、指定位置的隐藏向量 h，再训练线性分类器预测标签 c。这里的标签可以是语法属性或一个明确的关系类别。为了把表示变成类别概率，探针可采用如下形式：
\[P_{\phi}(c \mid h) = softmax(Wh + b)_{c}\]

这里 W 和 b 是探针的权重与偏置，φ 是它们的统称，下标 c 表示取第 c 类的概率。原语言模型参数保持冻结，只有探针更新；softmax 沿类别维度归一化。我们要测的是``这个小读出器能否利用 h 完成标签任务''，不是重新训练小助解决原问题。

如果探针在独立数据上表现很好，可以说明这些表示中存在可由该读出器利用的信息。它不能单独证明小助实际使用了这条信息。一个学生的草稿上写着正确公式，也可能在最后做题时没有用到它；探针与原模型后续计算同样不是一回事。

我们因此设置控制。训练与测试按句型和实体分组，防止只记住名字；与输入词频、位置等简单基线比较；用打乱标签检查是否只是高容量探针在记忆。我们尽量保持探针简单，并报告正则化与数据量。探针越复杂，越难区分``从原表示读取''与``读出器自己学会了任务''。

不同层的探针准确率可以帮助定位下一步实验，但不要把曲线峰值直接命名为``真正的知识层''。标签定义、读取位置与数据集变化都可能改变结论。我们会带着探针发现的候选位置，进入因果干预。

\textbf{停下来试一试} 固定一个小模型，按句型划分训练与测试，比较同一个简单探针在几层上的表现。加入随机标签与只用位置的基线。写出探针成功时能支持的最强结论，以及它还不能支持的结论。

\textbf{本节相关资料}
\begin{enumerate}
    \item Alain 与 Bengio，2016，\href{https://arxiv.org/abs/1610.01644}{Understanding intermediate layers using linear classifier probes} 。阅读重点：冻结模型、训练读出器的实验结构，以及表示可读出性与原任务行为的区别。
    \item Wang 等，2022，\href{https://arxiv.org/abs/2211.00593}{Interpretability in the Wild A Circuit for Indirect Object Identification in GPT-2 small} 。阅读重点：为什么机制分析需要把表示观察与更直接的行为干预结合。
\end{enumerate}

\section{激活修补 用干预检验计算路径}\label{激活修补 用干预检验计算路径}

我们准备一个比课程问答更容易控制的小任务。提示是``When Alice and Bob went to the library, Alice gave the book to''，模型应更偏向续写 Bob。把后半句的 Alice 换成 Bob，预期答案随之换成 Alice。这类例子让我们研究间接宾语识别（Indirect Object Identification，IOI），避免一开始就试图解释开放式长回答。

首先，我们确认所选模型在这批原始提示上确实表现出目标行为，并检查候选名字在 tokenizer 中是否各占一个 token。若候选是多 token，就要比较完整续写的对数概率，不能只看首 token。这里先使用单 token 候选，方便定义测量。

我们把末尾位置对 Bob 和 Alice 的 logits 分别记为 z 的下标 Bob 与 Alice。为了避免只看最终采样是否碰巧成功，用分数差衡量模型倾向：
\[\Delta z = z_{Bob} - z_{Alice}\]

Δz 越大，表示相对更偏向 Bob；它是 logit 差，不是正确率，也不必在 0 到 1 之间。对照输入改变了答案角色，所以应先确认其基线分数差与原始输入确实不同。若没有可测量的行为差异，后续``恢复''实验就缺少对象。

接着做激活修补（activation patching）：缓存原始运行某层、某位置的激活；运行对照输入时，只把这一处替换为原始激活，其他计算保持对照运行的状态；然后观察 Δz 是否朝原始方向恢复。这是在固定参数下修改一次前向计算，和改写权重的模型编辑不同。

图 \ref{fig:激活修补实验} 中，两次运行共享全部权重。竖向虚线只替换一个明确指定的中间状态；其后计算继续使用对照输入的其余状态。我们记录干预前后的 logit 差，而不是只挑一条采样成功的答案。

    \label{fig:激活修补实验}

如果一个位置的修补稳定恢复了倾向，我们获得了``在这组输入和干预方式下，这处状态携带了影响输出的信息''的证据。它不表示这里存着全部知识，更不表示找到了唯一原因。我们还要换不同名字、句型与对照方式复验，并修补无关位置作负对照。把不相容的激活硬塞进去，也可能制造偏离正常分布的状态。

我们再用消融（ablation）检查另一侧：移除、替换为均值或重采样某个组件的输出，行为是否受损？不同消融方式会产生不同分布偏移；冗余路径存在时，一个有作用的组件也未必是单独必要的。把多处组件与信息流组织成可重复检验的计算回路（circuit），才比一张``重要位置热图''更接近机制说明。

\textbf{停下来试一试} 对同一组提示比较不修补、候选位置修补、无关位置修补三种运行。保留每条提示的 Δz，而不只汇报最漂亮的一例。写清楚修补的是哪种激活、哪层、哪个 token 位置，以及对照输入怎样构造。

\textbf{本节相关资料}
\begin{enumerate}
    \item Wang 等，2022，\href{https://arxiv.org/abs/2211.00593}{Interpretability in the Wild A Circuit for Indirect Object Identification in GPT-2 small} 。阅读重点：怎样把一个可控行为分解成候选组件与计算路径。
    \item Zhang 与 Nanda，2023，\href{https://arxiv.org/abs/2309.16042}{Towards Best Practices of Activation Patching in Language Models Metrics and Methods} 。阅读重点：对照构造、度量和修补方式为什么会改变结论。
\end{enumerate}

\section{叠加表示与稀疏自编码器 一个神经元未必对应一个概念}\label{叠加表示与稀疏自编码器 一个神经元未必对应一个概念}

做完修补，我们查看一个候选神经元的高激活文本，发现它既回应课程说明，也回应某些代码片段。我们很想给它起名为``规则神经元''，但新的例子很快推翻了这个名字。问题可能在于：模型有用的特征并不总沿单个坐标轴排列。

叠加表示（superposition）研究一种可能性：许多特征利用不完全正交的方向共享有限维度。当每次只出现少量相关特征时，这种共享可能仍有用。它帮助我们理解为什么一个神经元可能响应多种模式，却不是所有神经元混杂行为的唯一解释，也不意味着任意向量方向都天然对应人类概念。

稀疏自编码器（Sparse Autoencoder，SAE）尝试把某层激活重新表示为一个更大的、但每次只激活少数项的特征向量。编码器把原激活 h 映射为特征 f(h)，解码器再重建出 h 的估计值。一个便于理解的训练目标，同时惩罚重建误差与特征激活的绝对值之和：
\[L_{SAE} = E_{h}\left\lbrack \parallel h - \widehat{h}2_{2}^{\parallel} + \lambda \parallel f(h) \parallel_{1} \right\rbrack\]

这里 h 是收集到的模型激活，h 上的帽号是重建值，第一项是平方重建误差；第二项的 1 范数表示各特征激活绝对值之和，λ 控制稀疏程度。这只是入门的 L1 型目标，实际 SAE 还有其他稀疏机制，并需约束解码向量尺度，防止仅靠缩放降低惩罚。训练 SAE 时，原模型保持冻结。

如果若干特征更容易用一致的文本模式描述，我们获得了更便于分析的坐标系。可``高激活样本看起来都像同一主题''仍是标签假设。我们还要找反例、看新数据、检验重建质量，并检查干预该特征后行为是否按预测改变。稀有特征可能被漏掉，过多特征也可能把一个概念拆成多份。

我们特别避免一句诱人的结论：``已经找到诚实特征，所以调高它就能保证模型诚实。''特征干预可能影响多种行为，也可能只对局部输入有效。SAE 是产生机制假设的工具，不是天然的真值坐标系，更不能替代前面建立的独立任务评估。

\textbf{停下来试一试} 先读一个公开 SAE 的特征例子，检查它展示了哪些高激活文本、是否有反例、是否报告重建与行为干预。若只有一个形象标签，请把它改写为可验证的模式描述，暂时不要称其为``某概念的开关''。

\textbf{本节相关资料与研究材料}
\begin{enumerate}
    \item Elhage 等，2022，\href{https://arxiv.org/abs/2209.10652}{Toy Models of Superposition} 。阅读重点：在可控玩具模型里，稀疏性与特征共享如何相互影响；与真实模型的结论分开。
    \item Gao 等，2024，\href{https://arxiv.org/abs/2406.04093}{Scaling and evaluating sparse autoencoders} 。阅读重点：稀疏程度、重建质量与评估如何权衡。
\end{enumerate}

\section{最小解释实验 从一个问题走到可复核的结论}\label{最小解释实验 从一个问题走到可复核的结论}

我们把可解释性入门收束成一次小实验，目标不是给小助画一张包罗万象的``大脑地图''，而是解释一个窄行为：在某类人物关系句子上，哪些中间状态影响下一名字的选择？我们选用可访问中间激活的小型 Transformer，先确保基线行为足够稳定，再开始分析。

第一步建立一小批原始与对照提示，按句型分出开发组和未见测试组。记录 tokenizer、模型检查点、候选 token、位置对齐方式与基线 Δz。若原始输入就经常失败，我们先缩小任务或换更合适的设置，不能用解释技术代替行为基线。

第二步只选择一种激活类型，例如每层指定位置的残差流（residual stream，即各组件输出通过残差连接累加的表示），逐处缓存与修补。每次只改一个对象，保存输入、源激活、目标位置和输出分数。可视化各位置的恢复情况，是为了筛选候选，不是立即给每层赋予语义。

第三步固定筛出的少量候选，在未见名字与句型上复验，加入无关位置和相同输入自修补等控制。检查效果是否依赖一个特殊对照，是否牺牲其他行为。需要时再补线性探针或细分到注意力头；不要同时更换任务、模型、指标与干预方式。

最后写报告时，我们把``事实观察''\,``机制假设''\,``未排除的解释''分开。一个清楚的结论可以是：``在该模型和这类句子上，把第某层某位置的原始残差激活移入对照运行，会使候选分数差向原始方向移动。''这比``模型在这一层理解了人类关系''克制，但也更有内容，因为别人能够复查和推翻它。

我们现在可以把这一章接回训练诊断。内部分析能帮助提出新假设，比如输出头是否改变、某条纠错路径是否受损；要证明修复对真实用户有用，仍需回到独立题集、旧能力回归和成本评估。机制证据与行为证据相互补充，才让我们的解释既具体，也不超出实验所能支持的范围。

\textbf{停下来试一试} 用一页实验记录写出问题、假设、原始与对照输入、干预、负对照、未见测试和结论边界。若无法获得模型内部激活，就先完成设计和行为基线，明确哪些因果问题暂时不能回答。
